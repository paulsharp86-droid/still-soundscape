# STILL Beta 0.5

Upload the contents of this folder into the root of the GitHub Pages repository, replacing the existing files.


## Beta 0.5 additions
- Full 7-note scale and pentatonic mode selector
- Basic neighboring scale-degree movement, occasional wider movement, and short-term note memory
- Chord-tone weighting between C major and A minor
- Occasional cross-instrument response
- All Noise, No Noise, Sleep, and Custom presets
- Local browser storage remembers the current settings

## Important
This remains a synthesized native Web Audio prototype. It does not yet use SoundFont samples, and its audio behaviour still needs listening tests and tuning. All files are self-contained/offline-friendly.
